# LaLea MVP 開發範圍凍結與執行清單

> 狀態：等待使用者確認開始開發  
> 最後更新：2026-08-21  
> 本文件完成後停止增加開發前規格

## 1. 已確認產品目標

- 手機優先的多語言學習平台。
- 第一條路徑：繁體中文輔助 → 一般商務英語。
- 強化單字、片語、聽力與自然職場表達。
- 單元可在 1–3 分鐘完成並支援中斷續接。
- 第一階段供個人使用，但資料與權限從一開始支援多使用者。

## 2. 已確認技術基線

- Next.js + TypeScript。
- PostgreSQL + Drizzle ORM。
- Linux 自架，第一版使用主機既有 PostgreSQL。
- Next.js 與 PostgreSQL 預設同機。
- Passkey + 一次性恢復碼。
- 預生成音訊優先，本地 TTS 產生，瀏覽器 TTS 備援。
- 簡化可解釋的複習排程器。

## 3. 第一個可開發垂直切片

第一輪正式開發只完成一條端到端流程：

```text
開發環境登入／測試使用者
→ 首頁顯示下一個單元
→ 開始內容原型 01
→ 完成選擇、聽力、句塊與固定分支對話
→ 每題保存結果與回饋
→ 中途離開與續接
→ 完成後建立簡化複習排程
→ 首頁顯示更新後進度
```

第一個切片完成前，不平行擴充完整詞彙注入、YouTube 或 AI 工作台。

## 4. MVP 必做

### 帳號與安全

- Passkey 註冊與登入。
- 一次性邀請建立第一位使用者。
- 恢復碼與受限恢復 session。
- 伺服器 session、登出與撤銷。
- 使用者資料隔離測試。

開發初期可用明確標記的本機測試登入加速介面工作，但 production build 不得啟用。

### 學習

- 首頁的繼續學習。
- 1／3／5 分鐘與環境模式。
- 共用學習播放器。
- 選擇題、聽力辨識、句塊排序、固定分支對話。
- 所有題目顯示對錯、正確答案與簡短原因。
- 選項與句塊亂序。
- 每題提交後保存。
- 中斷與續接。
- 完成回饋。

### 教材

- 三堂一般商務英語內容原型。
- 教材與題目版本。
- 經審核的固定答案與回饋。
- 內容來源與審核狀態。

### 詞彙與複習

- 詞彙、詞義與翻譯。
- 個人詞彙狀態。
- 閱讀、聽力與主動提取的獨立掌握度。
- 簡化間隔排程。
- 到期複習優先。
- 完整不可變作答及複習事件。

### 音訊

- 固定音訊播放。
- 播放、暫停、重播與速度。
- 漸進式英文字幕。
- 純聽清單與「不熟」標記。
- 被動播放只記曝露。
- 瀏覽器 TTS 安全降級。

### 詞彙注入

- 手動加入單一單字或片語。
- 查找既有詞義。
- 無資料時保存待補齊項目。
- 人工確認後進入首次學習。

### 部署

- Drizzle migration。
- Linux systemd 服務。
- Reverse proxy + HTTPS。
- 健康檢查。
- PostgreSQL 專用資料庫與最小權限角色。
- 每日備份與至少一次還原演練。

## 5. MVP 明確不做

- 開放式文字或語音問答。
- 即時 AI 對練或 AI 語意評分。
- 自動發音評分。
- 網站直接執行 Codex／Claude 訂閱 CLI。
- YouTube 自動擷取或下載。
- 半導體／PCB 專業課程。
- 英文以外的正式教材。
- 公開註冊、社群、排行榜或好友。
- 付費訂閱與商業計費。
- 原生 iOS／Android App。
- 完整離線模式。
- 複雜管理後台。

## 6. 開發階段

### Phase A：專案骨架

- 建立 Next.js + TypeScript。
- 程式品質工具與測試框架。
- 環境設定驗證。
- PostgreSQL／Drizzle 連線。
- 最初 migration。
- 健康檢查。

### Phase B：第一個垂直切片

- 內容原型 01。
- 首頁、播放器、四種題型、回饋與完成。
- 每題保存、中斷與續接。
- 第一版排程。
- 手機尺寸測試。

### Phase C：內容與詞彙

- 內容原型 02、03。
- 詞彙庫與手動注入。
- 三種掌握度與到期複習。
- 教材版本及審核狀態。

### Phase D：音訊與純聽

- 預生成音訊管線。
- 字幕、調速與純聽清單。
- iPhone Safari、Android Chrome 實機測試。
- 背景播放實驗。

### Phase E：登入與部署

- Passkey、恢復碼及 session。
- Linux 主機盤點與部署。
- HTTPS、備份及還原演練。
- 安全與資料隔離測試。

Phase E 可在較早階段建立必要骨架，但正式帳號需等固定網域與 HTTPS 確認。

## 7. 開始開發前的外部條件

不阻礙本機開發：

- 正式網域尚未確定。
- Linux 主機尚未盤點。
- 正式 TTS 引擎尚未選定。

部署前必須完成：

- 固定網域與 RP ID。
- HTTPS 與 reverse proxy。
- Linux 唯讀盤點。
- PostgreSQL 專用資料庫／角色。
- 異機備份目的地。

## 8. 開發完成的共同定義

一項功能只有在以下條件皆成立時才算完成：

- 手機與桌面基本操作可用。
- 有必要的單元或整合測試。
- 錯誤、空白、載入與中斷狀態已處理。
- 多使用者資料存取有權限測試。
- 資料庫變更有 migration。
- 沒有把憑證或敏感資料送進瀏覽器或日誌。
- 對應規格及決策紀錄已更新。
- 不依賴只能在目前 Windows 工作區運作的設定。

## 9. 開發啟動門檻

現在已具備開始本機 Phase A 的產品與架構資訊。正式建立專案前只需要使用者明確確認：

> 開始正式開發 LaLea MVP，依 `MVP_DEVELOPMENT_CHECKLIST.md` 執行，先完成 Phase A 與第一個垂直切片，不擴大範圍。

在收到此確認前，維持目前只有規格文件與可拋棄原型的狀態。
